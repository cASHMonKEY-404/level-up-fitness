# LEVEL UP — Complete Figma design kit

This kit follows the supplied dark design direction with purple Steps, green Workouts, magenta Nutrition and category colors for the macros. It contains **77 editable iPhone screen designs**, a Figma importer, SVG exports, original icons, reusable components, and prototype destinations. All values are sample design data. App code and the original Figma file have not been modified.

## Import native editable frames into Figma

Use **Figma desktop** for local development plugins:

1. Open your LEVEL UP design file, or create a new file.
2. Choose **Plugins → Development → New plugin**. Create a Figma Design plugin with a **Run once / without UI** template. Save its generated files to a folder on your computer. Figma supplies the plugin ID and manifest for this local plugin.
3. Replace that folder's generated `code.js` with this kit's `code.js`. Keep the manifest generated by Figma; this kit does not invent or require a published plugin ID.
4. Run the plugin from **Plugins → Development**.
5. The importer creates two new pages: **LEVEL UP · Complete screen flows** and **LEVEL UP · Components & tokens**. Existing pages are preserved. It selects Today when complete.
6. Select the Today frame and click Present to review prototype links. The fields and calculations are design states, not a running application.

The importer creates native Figma rectangles, frames, text, vector icons, paint styles, and button/input/card components. It tries Inter first, then available font fallbacks. Prototype destination IDs are also retained as plugin data. The importer uses no network and reads no user activity data.

## Review the clickable design before importing

Open `review.html` in a desktop browser. It is a self-contained click-through prototype with a screen index; it does not log real activity. Alternatively, view `preview.png` for six representative screens.

## Import without running a plugin

Drag any SVG from `screens/` onto your Figma canvas. The layout imports as editable vectors/text rather than a bitmap. Imported SVGs do not carry prototype links; the native importer is recommended for full editing and click-through navigation. Text wrapping can vary slightly with fonts. The individual SVG frames also open directly in a browser.

## Coverage

- Today dashboard and optional welcome.
- Steps, weekly history, walk entry/edit, seconds, distance/speed/incline/calories, step-length and cadence methods, separate versus included estimates, manual replacement totals.
- Workout selection, scheduling, swapping, rescheduling, upper body/full body/lower body/cardio. Every strength exercise has a detail and guidance variant; treadmill uses the walk flow.
- Actual set/rep/weight logging, incomplete sessions, review and completion.
- Nutrition totals, macro progress, food logs, reusable saved foods, recently logged, search, custom food, serving adjustment, barcode entry and scan review.
- Editable targets, history, level/XP/milestones, local-data explanation.
- Empty, loading, denied-camera, missing-product, incomplete-label, network/storage error, destructive confirmation and unsaved-exit states.
- Color/type/spacing reference and implementation review notes.

## Behavior decisions

- The new Upper Body design has five exercises, adding floor chest press to the original four; all use existing icons. 3 × 10 is a proposed editable starting suggestion, not tracked activity.
- The 2.74 mi example estimates **6,200 steps** with a 28-inch step length. 110 measured steps/min over 54:20 estimates **5,977**. Incline and treadmill calories are reference values, not step inputs.
- Daily steps remain 6,240 when the new estimate is saved separately, or become 12,440 when its 6,200 steps are explicitly added. The prototype includes both branches.
- Serving example: 100 kcal / 17g protein / 6g carbs / 0g fat per serving, multiplied by two, yields 200 kcal / 34g / 12g / 0g.
- Missing nutrients remain unknown. Treadmill calorie readings never silently increase the food budget.
- Existing rules remain: 120 XP for a saved workout, 25 for the first food entry per day, 50 at 8,000 daily steps, 500 XP per level. Planning, recalculation and repeated saves do not duplicate rewards.
- Targets are editable starting points, not personalized nutrition advice. Local history is retained when targets or plans change.
- Design values are placeholders, never the user's real history.

## Limitations

The source Figma file could not be read or edited from this chat. This is a new screen set based on the uploaded overview, not a verified modification of the existing frames. **The Figma importer has been syntax-checked and simulated locally; execution in Figma itself is not yet verified.** It deliberately does not claim to be a `.fig` file. The SVG exports and previews are available independently of the importer.
