LEVEL UP — minimal exercise pictograms

12 original monochrome SVG icons plus a labeled SVG preview sheet.

The individual icons are transparent, have no visible text, and use a 256 x 256 viewBox. All artwork uses real vector paths and circles. No embedded raster images, fonts, scripts, external resources, facial features or clothing decoration.

Default color: #242127. Fill and stroke use currentColor. Override the SVG color attribute or apply CSS color to recolor the entire icon, including lavender for the LEVEL UP app.

Import into Figma, Illustrator or Inkscape for editing. In a browser, SVGs scale to any size. The figures identify exercises; they are not instructional movement demonstrations.

This is original artwork inspired by the broad pictogram style of the reference. It does not trace or reproduce the reference stock illustrations.

The earlier ponytail illustrations are preserved separately. These new pictograms use abstract heads without hair detail. App functionality and screens have not been changed.
