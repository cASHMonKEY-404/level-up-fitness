LEVEL UP — Nutrition icons

Four original minimal SVG icons:
01-protein.svg — drumstick
02-carbs.svg — wheat stalk
03-fat.svg — oil droplet
04-calories.svg — flame

Transparent backgrounds, no visible labels, real editable vector paths, accessible titles/descriptions. No embedded bitmap images, external resources or font dependencies in individual icons.

The files use a 64 x 64 viewBox and default 256 x 256 display size. All fills and strokes use currentColor. Set the SVG color attribute, or CSS color when using inline SVG, to use your lime accent, white or lavender. For an SVG loaded via an img tag, change the file color attribute or import and recolor in your design tool.

The preview shows the same four glyphs in black on white and green (#76FF03) on charcoal. These are macro/energy category icons, not claims about the source or nutritional value of a specific food.

App code has not been changed.
